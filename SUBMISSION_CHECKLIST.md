# Submission Checklist

1. Create/activate a Python 3.10-3.12 virtual environment.
2. `pip install -r requirements.txt`
3. `pytest -q`
4. `python main.py`
5. Verify `output/final_dataset.csv`
6. Verify `output/summary_report.json`
7. Verify `logs/scraper.log`
8. Open README.md and AI_USAGE.md and make sure they accurately describe what you did.
9. Submit the project using the assignment submission form.
